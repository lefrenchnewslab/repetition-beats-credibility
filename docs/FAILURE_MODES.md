# FAILURE_MODES — illusory-truth circuit, sprint Block A
**Sections A–D: copied unchanged from the pre-sprint pilot (`pilot_illusory/FAILURE_MODES.md`, 11 Nov). Section E: SPRINT WORK, written 2026-11-13 BEFORE any Block A code or data.** Where E supersedes a pilot guard, E wins (e.g. C2: the pilot's 70/30 split is replaced by the 200/400 entity split).

Every way this pilot could produce a misleading signal, and the design choice that guards against it.

## A. Behaviour (Step 1–2)

| # | Failure mode | What it would fake | Guard |
|---|---|---|---|
| A1 | **Position / recency**: the low claim's copies sit closer to the question, so "repetition" is really "the last table wins". | Repetition effect | Every prompt in both table orders (gov block first / low block first); report each order separately as well as pooled. C6 (gov repeated) is the mirror: if repetition is real, it should push the *other* way. |
| A2 | **More tokens, not repeated content**: k copies add ~k×60 tokens of context; length alone may shift the decision. | Repetition effect | C5: one low table + 3 filler tables (unrelated fictional entity, no source label) placed where copies 1–3 sit in C2 k=4, so the low claim keeps the position of the copy nearest the question and total length/table count match C2 k=4. Report token counts of C5 vs C2 k=4. |
| A3 | **Answer-letter bias (A vs B)**, and confusion between "Table A/B" captions and answer "(A)/(B)". | Any effect, if letter and condition co-vary | Answer order counterbalanced independently of table order (high value as (A) in half, as (B) in half). Score = P(letter of low value) after A/B softmax, so letter bias cancels in the pooled mean. Report per-answer-order means. |
| A4 | **Value priors**: one of the two conflicting values is more plausible a priori (e.g. "teacher" vs "astronaut"). | Source/repetition effects at item level | Value-to-source assignment swapped within every pair (each value is the low value in half the variants). C0 (no labels) gives the per-variant baseline; the shift is computed against it. |
| A5 | **Fictional entities leak real knowledge** (a real person/town; a value the model "knows"). | Prior beats context | Names built from random syllables, places invented; checked by C0: if C0 P(low) is far from 0.5 on average for a value pair after swapping, the value set is leaky. Report C0 |P−0.5| distribution. |
| A6 | **Refusal / non-answer**: chat model wants to say "I cannot verify". | Noise or artefact | No generation. Next-token logits only; renormalised over the two letters (Schuster's scoring). Also record raw P(A)+P(B) mass; if mean mass < 0.5 for a model, flag it — the A/B softmax is then hiding a non-answer. |
| A7 | **Chat-template / tokenisation mismatch**: letter token is " A" vs "A" depending on model. | Wrong numbers | Read letter token ids from the tokenizer for both "A" and " A"; take the max-mass variant per model, logged. Sanity check: C0 with identical values on both sides should give ~0.5 after counterbalancing. |
| A8 | **Ceiling/floor**: if C1 already prefers social (no credibility effect), "flip" is meaningless. | GO on a broken premise | Report C1 shift vs C0 first. Credibility effect must exist (C1 P(low) < C0) for the repetition question to make sense. |
| A9 | **Repetition = majority, not credibility override**: the model may count content blocks regardless of labels. | Misattributing to "illusory truth" | Added control C0r: no source labels, low value ×4. If C0r ≈ C2 k=4, labels are irrelevant to the repetition effect. |
| A10 | **Small-n / one seed**. | Spurious GO | 200 pairs × 8 counterbalanced variants per condition; item-level bootstrap 95% CIs on every shift. |

## B. Localisation (Step 3)

| # | Failure mode | Guard |
|---|---|---|
| B1 | **Clean (C1) and corrupt (C2 k=4) have different lengths** → no token alignment for patching. | Patch only on the shared suffix (question + answer options + chat tail), aligned from the end. This localises heads that *move* the decision into the answer positions (the "decision head" sense). Stated as a scope limit; heads acting only inside table tokens are invisible here. |
| B2 | **Attribution patching is a linear approximation**, wrong for saturated/nonlinear components (esp. layer 0 / attention-pattern changes). | Verify the top-10 heads by real activation patching (individually and jointly top-5/top-10) and mean ablation; report AtP-vs-real rank agreement. |
| B3 | **Recovery fraction inflated by a tiny denominator** (if C2–C1 logit diff is small). | Report the raw logit diffs; only compute recovery on items where C2 k=4 − C1 > 1 logit. |
| B4 | **Heads found are letter-bias or format heads**, not repetition heads. | Logit diff = logit(low letter) − logit(high letter), with letters counterbalanced; heads must move it in the same direction under both answer orders. |
| B5 | **Mean ablation disrupts everything** (any important head kills the output). | Report patching (clean→corrupt) as primary; mean ablation secondary; compare against 10 random heads. |
| B6 | **Attention to copies just reflects that copies are many tokens**. | Report attention mass per copy and per token, and compare with attention to the gov table of equal length. |

## C. Representation (Step 4)

| # | Failure mode | Guard |
|---|---|---|
| C1 | **Probe decodes surface tokens / answer letter, not credibility.** "Which option is gov-sourced" correlates with the predicted letter whenever gov wins. | Test where the output FLIPS (C2 k=8): if the probe tracks the predicted letter it should fall to ≤ chance there; if it tracks the source it stays high. Report probe accuracy restricted to items the model answers with the low value. Control probe on C0 (no labels, same "would-be-gov" label) must be ≈ 0.5. |
| C2 | **Leakage across entities** (probe memorises entity/value identity). | Held-out entities: 70/30 split by pair id. |
| C3 | **Train/test distribution shift masks the signal** (k=1/2 → k=4/8 is a length shift). | Also report in-distribution AUC (held-out entities, same k) as a ceiling. |
| C4 | **Copies-vs-independent probe is trivially surface-decodable**: C3 contains several distinct usernames, C2 one repeated name. High AUC ≠ an epistemic distinction. | Report it, but interpret as "available in the residual", not "used". The informative quantity is whether behaviour differs (C2 vs C3) — Schuster: barely. |
| C5 | **Overfitting high-dim probes on few thousand points.** | L2 logistic regression, C chosen on in-distribution validation only; held-out entities. |

## E. New in sprint Block A (written 2026-11-13, before code)

| # | Failure mode | What it would fake | Guard |
|---|---|---|---|
| E1 | **Entity reuse from the pilot**: a v2 entity, filler, place or username word was also in the pilot data, and the pilot results were read. | Contamination of "fresh" data | The v2 builder loads `pilot_illusory/data/pairs.jsonl`, puts every pilot-generated word into the `used` set before generating, uses a new seed (20261113), and asserts zero overlap of entity names, filler names, places and usernames with the pilot. The overlap counts go in the manifest. |
| E2 | **Selection/test leakage**: the same entity, gov place or username appears in both splits, so the heads and probes chosen on selection "generalise" through memorised surface tokens. | Inflated held-out recovery / AUC | Split by entity (200 selection / 400 test). Places and gov offices are drawn from **disjoint pools per split**, and usernames are unique per pair. Asserted in the builder. |
| E3 | **Mean-ablation reference built from test items** leaks test information into the ablation. | Inflated mean-ablation recovery | Mean head outputs are computed on selection-split items only. |
| E4 | **Peeking at the probe layer**: choosing the best layer on test AUC. | Inflated probe criterion | The layer for the pre-registered probe criterion is chosen by the AUC of a held-out-entity fold *inside the selection split*. Every layer's test AUC is still reported, but the criterion uses the pre-chosen layer only. |
| E5 | **C7 paraphrase changes the value** (e.g. "1,234" vs "1234", "Nurse" vs "nurse"). | C7 ≠ same claim; a C7 < C2 gap would be a value change | Value strings are byte-identical across all copies (asserted). Only the field labels, row order, header (F1) and frame sentence (F2/F3) change. |
| E6 | **C7 is barely reworded** (templates leave copies near-identical), so C7 ≈ C2 is trivially true. Or C7 is **less fluent** than C2, so C7 < C2 reflects template quality, not "reworded copy". | Wrong conclusion on exact-copy induction vs content counting | Measure and report the mean pairwise token-Jaccard between low-credibility blocks in C2, C7 and C3. The paraphrases are deterministic templates written by hand (stated in the report, no LLM paraphraser), and copy 1 of C7 is the canonical C2 block. |
| E7 | **Attribution verb confound (F2)**: "According to the Ministry" vs "A user claimed" puts a hedge verb on the social source only, so the effect could be the verb, not the source. | Credibility effect driven by wording | Canonical F2/F3 frames are **matched**: the same sentence frame for both sources ("According to {source}, …"), and only the source string differs. Varied frames appear only inside C7 social copies. |
| E8 | **Letter collision in new formats**: documents labelled A/B collide with answer letters. | Letter bias (A3) | F1 keeps the pilot's "Table A/B" (Schuster's format, comparable to the pilot). F2 uses "Excerpt 1, 2…" and F3 "[Document 1], [Document 2]…", which have no letters. Answer letters stay counterbalanced. |
| E9 | **Answer mass collapses in prose/RAG formats** (the model wants to write a sentence). | A/B softmax hides non-answers | Report mean P(A)+P(B) per model × format, and flag any value < 0.5 as in A6. |
| E10 | **Cross-format comparison on different items**: F2/F3 run on the test split only, F1 on both splits. | Format differences that are really split differences | All cross-format numbers use the F1 **test split** (same 400 pairs). |
| E11 | **Shared suffix differs by format**, so F3 heads come from a different patched region. | False rank instability between F1 and F3 | Within a format the clean and corrupt prompts share the suffix by construction (asserted: S ≥ 10 tokens, and identical question/options). Rank stability between formats compares heads ranked on the same split (selection) and the same item keys. |
| E12 | **Rank stability measured on unequal samples**: AtP on 96 selection items vs a different number on test. | Spurious low Spearman/Jaccard | Rank on the same number of items in both splits. Also report a split-half baseline inside selection, as a noise ceiling. |
| E13 | **The random-head baseline has a fat tail** (with 3 draws, the pilot could miss it). | Overstated specificity | ≥ 20 random 10-head draws for patching (and 5 for mean ablation). Report the max and the 95th percentile, not just the mean. |
| E14 | **Recovery CI ignores item variance.** | Overconfident recovery | Bootstrap over held-out items (2,000 resamples) of the ratio-of-means recovery. |
| E15 | **Hidden-state RAM blow-up** (≈ 48k probe prompts × all layers) → OOM kill late in the job, after the GPU hours are spent. | Lost run | Store every 2nd layer (plus the last), in bf16, for the probe conditions only. Write behaviour rows to disk *before* fitting probes. |
| E16 | **Qwen2.5-32B in bf16 on one A100 80 GB**: 65 GB of weights leaves ~14 GB for activations; long C2 k=8 prompts OOM. | Lost run / truncated data | Behaviour only, no hidden states, `logits_to_keep=1`, a token budget per batch sized by the smoke test, and an OOM back-off that halves the batch. Hard cap of 2 A100-h: the job time limit is set at 2 h and the condition subset is fixed in advance. Skip and report if it does not fit. |
| E17 | **Many comparisons (3–4 models × 3 formats × 16 conditions)** → some "effects" by chance. | Cherry-picked effects | Everything goes in the tables. The headline claims are only the pre-registered ones plus the C2/C3/C7/C5 contrasts named in the prompt. CIs are reported for every shift. |
| E18 | **Probe (a) trained on all labelled conditions also learns "number of blocks"**, so it fails on C1 vs C2k8 for reasons of length, not credibility. | Lower AUC misread as "credibility lost" | Report the per-condition test AUC. The flipped-only C2 k=8 AUC is the key cell, together with the C0/C0r control at ~0.5. |
| E20 | **The probe decodes lexical identity, not credibility** ("which option is gov" could be read off which surface strings co-occur). | "Credibility represented" overclaimed | Amendment 2: three lexical baselines on the same label/splits (layer-0 final token, which is constant and so 0.5 by construction; mean-pooled input embeddings; TF-IDF 1–3-grams). H3 requires them to be ≤ 0.65 and ≥ 0.20 below the probe. |
| E21 | **The gov-vs-social direction is a binary source detector, not a credibility axis.** | Same overclaim | Graded test: newspaper and person sources (never seen in probe training) must project between gov and social, in Schuster's order. The partner is a social user in every prompt, so the score isolates source X. A social-vs-social control (X = a second user) anchors the bottom. |
| E22 | **Graded levels confounded with label length/format** (gov labels are long multi-word titles; persons are two words). | Ordering by length, not credibility | Report the ordering together with each level's mean label token length. Newspaper (3–4 words) and person (2 words) bracket each other in length but not in expected credibility, so a pure length effect would put newspaper > person > social *and* gov highest by length too — not separable for gov. State it as a limitation. |
| E23 | **H2 measures tag–value binding, not credibility.** Any two distinguishable tags could be bound to their values just as well. | "Credibility represented" overclaimed from a binding probe | Amendment 3: neutral Blue/Green binding control with the same recipe and splits. If it reaches ≥ 0.95, the credibility claim rests only on H3. Neutral prompts projected onto the gov-vs-social direction must sit near the midpoint. |
| E24 | **The neutral control leaks into the main probe sets** (same entities as graded/test). | None for the main probe (no fitting on test), but neutral-selection must not reuse test entities | Neutral-selection uses selection-split pairs; neutral-test uses test-split pairs. The main `cred_all` probe never sees neutral prompts. |
| E25 | **Symmetric comparison cannot place a source on a scale**: Blue vs Green (like social vs social) projects ≈ 0, whatever the absolute credibility of the tags. | A false "neutral sits at the midpoint" | Amendment 4: Blue-vs-Green is only a sanity check. Neutral is placed with an asymmetric comparison (Blue vs social user), as a 5th graded level, reported as a normalised position between social (0) and gov (1). Exploratory, outside H3. |
| E26 | **Gov = singleton in every k ≥ 2 training condition**, so the credibility probe can read "minority value" instead of source. Seen: Llama cred_all AUC 0.997 on C0r. | H2 met for the wrong reason | Amendment 6: a C1-only probe (no count asymmetry), tested on C0r (no labels) and C6 (gov = majority), with source-vs-count predictions written before fitting. |
| E19 | **"Best model" for the F3 head analysis picked after looking at F3**. | Selection bias | Fixed before F3 runs: the model with the highest F1 held-out top-10 recovery. The choice is computed inside the job script. |

## F. Block B (mechanism + training-free fix) — written 2026-11-13 ~22:40 CET, before any Block B code or job

| # | Failure mode | What it would fake | Guard |
|---|---|---|---|
| F1 | **Induction scores on random-token sequences don't transfer** to the prompt distribution (a head can copy in tables without scoring on random tokens, or the reverse). | A wrong "is / is not an induction head" | Standard recipe (Olsson et al.) for comparability, plus every head's score so the top-10 are ranked against the whole model, not an absolute cut alone. The C7 (paraphrase) heads are scored too: a paraphrase has no token-level repeat, so equal induction scores for C2 and C7 heads argue against induction as the C2-specific mechanism. |
| F2 | **Prefix-matching inflated by attention sinks** (BOS, first token) or previous-token heads. | Spurious induction | Score = attention mass on the exact induction target (the token after the previous occurrence), not on "anything earlier". The previous-token score is reported alongside. |
| F3 | **Copying score (direct logit attribution) ignores the final norm** or Gemma's logit softcap. | Wrong copying sign/size | DLA uses the actual per-position RMS scale and the effective norm weights (`final_norm(ones)`). Mean over the vocabulary is subtracted. Rankings are relative to all heads. |
| F4 | **Steering needs the sign of the gov option** (the direction encodes "option A is gov"), so as a *fix* it uses oracle knowledge of which option is official. | An unrealistic fix | B2 is a mechanism test. B3(b), steering as a fix, is labelled **oracle upper bound, exploratory**. Only B3(a) head scaling is source-agnostic. |
| F5 | **Large steering norms push P_low toward 0.5 regardless of direction** (the model breaks). | "Steering works" | ≥ 20 random directions at the same norm with the same per-item sign rule. Criterion: random |ΔP_low| < 1/3 of the direction's. A+B mass is reported at α\*. |
| F6 | **α, k or γ chosen on test.** | Inflated fix | Every hyper-parameter is chosen on SELECTION items. The full test grid is reported as a table, but claims use the selected setting only. |
| F7 | **Head scaling damages general ability.** | A fix that is not deployable | MMLU (500 fixed items) accuracy and WikiText perplexity (200 paragraphs), base vs fixed, with paired bootstrap CIs. |
| F8 | **The fix kills all aggregation** (it also ignores genuinely independent corroboration, C3). | A blunt "ignore the majority" sold as selective | Corroboration retained (C3k4) is reported, with a pre-registered acceptability bar. |
| F9 | **The fix shifts letter/position bias**, which can look like credibility under one answer order. | A fake fix | Counterbalanced variants; HF/LF and AH/AL breakdowns; C0 must stay ≈ 0.5. |
| F10 | **The F1 head set doesn't transfer to F3/C7.** | A fix that fails where it matters | Branch rule on Jaccard(F1/C2, F3/C7), decided before B3 and written in RESULTS_B. |
| F11 | **The C1 baseline also moves under the fix**, so "bias reduction" is computed on a shifted base. | Mis-scaled metric | The metrics use fixed-model C1 in the numerator and base-model C1 in the denominator, as specified; P_low(C1) base vs fixed is reported separately. |
| F12 | **Path patching receivers are under-specified** (which inputs of the decision heads, at which positions). | An arbitrary "mediated %" | Receivers = the top-10 heads' attention inputs (q, k, v) on the shared suffix, the same scope as Block A's patching. Senders = every head and MLP in earlier layers. Stated as a scope limit. |
| F13 | **Time/budget**: B1 is the most expensive and least needed. | An unfinished report | Priority B0 → B3 (Qwen) → B2 → B3 replication → B1. B1 is skipped if B0–B3 are not done by Sat 18:00 Cairo (Amr). |

## G. Block D (trained LoRA baseline, Qwen-7B) — written 2026-11-14 ~11:30 Cairo, before any Block D code, data or job

| # | Failure mode | What it would fake | Guard |
|---|---|---|---|
| G1 | **Training entities leak into selection/test** (shared names, places, users). | An inflated test score | New seed and new place pools; every word from v2 (selection + test) and the pilot is excluded. Assert zero overlap of entity names, filler names, places and usernames with v2 and the pilot. |
| G2 | **Hyper-parameters tuned on selection or test.** | An optimistic LoRA | lr and checkpoint (end of epoch 1, end of epoch 2, after refinement) chosen by validation loss on held-out *training* entities only. Selection and test are not read until the final evaluation. |
| G3 | **Shortcut: "pick the singleton block".** In every training item the gov value is the singleton and the teacher prefers it, so the LoRA could learn "minority wins" instead of "ignore repetition". | A fix that only looks right on C2/C7 | Held-out side-effect conditions: **C6** (gov repeated; a minority shortcut would pick *social*), **C3** (independent users), **C0r** (no labels, repeated) and **C0**. | G4 | **In-distribution training is not Schuster's setting.** They train on other source pairs (circulation, gender, person vs newspaper) with one repeat and test transfer to gov vs social; we train on gov vs social (new entities) with k = 2/4 copies and paraphrases. | An unfair comparison with their 79% / 72.5% | Stated as a deviation. | G5 | **Capability damage.** | A non-deployable fix | The same 500 MMLU items and 200 WikiText paragraphs as B3; base values reused from B3's cap file (same items, same base model). |
| G6 | **Answer mass leaves A/B** (training sees only the 2-way softmax). | A hidden refusal-like shift | Report mean P(A)+P(B) per condition, base vs LoRA. |

| G9 | **Matched comparison outside the B3 curve range.** | An arbitrary verdict | B3 curves include the base point (γ = 1: reduction 0, preference 1); below the curves' minimum preference, the most aggressive point (γ = 0) is used. Rule fixed below. |
